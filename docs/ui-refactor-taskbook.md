# UI / 交互重构任务书

> 版本：2026-11-24  
> 适用范围：数字员工控制台前端（Vue 3 + Vite）  
> 关联文档：`docs/core-business-taskbook.md`

## 0. 为什么要重构

当前控制台的问题不是“页面不好看”，而是**产品对象错了**：

- 数字员工被当成普通 CRUD 实体：表格 + 大下拉 + 一排同级按钮。
- 创建员工时无法选择已有 Agent，Agent 与员工的关系断裂。
- 选中员工后没有“工作台”，看不到状态、工作、项目、Token 去向。
- 没有对话入口，无法像使用大模型一样直接指挥数字员工调用工具。
- 没有群聊，多员工协作只存在于后端任务里，用户不可见。
- 表单、空状态、加载、错误、权限提示缺少统一规范。

本次重构把产品中心从“后台配置”改为**数字员工工作台**。

## 1. 目标与非目标

### 目标

1. 以数字员工为中心组织导航和操作。
2. 创建员工时从已有 Agent 中选择，Agent 可复用。
3. 选中员工即可看到：状态、工作记录、参与项目、Token 明细。
4. 提供“去对话”：类大模型对话窗口，但数字员工可在对话中调用工具。
5. 支持把多个数字员工拉进一个群聊。
6. 统一交互规范，淘汰“大下拉 + 表格 + 一排按钮”的主流程。
7. 保留现有学习、契约、技能、知识库、审批等能力，作为员工工作台的下钻配置。

### 非目标

- 不在本次重写所有业务页（AIGC、审批、质检等）的视觉。
- 不引入新的前端框架。
- 不为了动画牺牲可读性和加载速度。

## 2. 信息架构

### 2.1 左侧导航（建议）

```text
工作台
  运行概览
  数字员工        ← 核心入口
  会话            ← 新增
  任务中心
  学习中心
  训练数据
组织与团队
  岗位模板 / 团队模板 / 我的团队 / 项目
知识与风控
能力接入
  Agent / 技能市场 / 工具 / MCP / 接口登记
治理
```

### 2.2 数字员工页 = 名册 + 工作台 + 对话坞

```text
┌──────────────┬────────────────────────────────────┬──────────────┐
│ 员工名册      │ 员工工作台                           │ 对话面板      │
│ 搜索/筛选     │ 头像 姓名 岗位 状态 绑定Agent        │ 消息流        │
│ 状态/当前任务 │ [概览][工作][项目][Token][学习][配置] │ 工具调用卡片   │
│ 今日Token     │ 内容区                               │ Composer      │
└──────────────┴────────────────────────────────────┴──────────────┘
```

- 名册支持搜索、状态过滤、按团队/项目过滤。
- 工作台头部显示：状态（空闲/工作中/等待确认/停用）、当前任务、绑定 Agent、
  今日 Token、最近活跃时间。
- 对话面板可折叠；宽屏右侧常驻，窄屏改为抽屉。

### 2.3 左下角员工坞

在全局壳层左下角（导航底部上方）固定显示当前选中的数字员工：

```text
┌──────────────────────────────┐
│ [头像] 员工名 · 岗位           │
│ ● 工作中 · 当前任务标题        │
│ 今日 12.4k tokens             │
│ [去对话] [拉群] [打开工作台]   │
└──────────────────────────────┘
```

- 点击“去对话”打开对话抽屉。
- 点击“拉群”进入群聊创建。
- 未选择员工时显示“选择一个数字员工开始工作”。

## 3. 核心页面

### 3.1 数字员工名册

- 卡片/紧凑列表二选一，默认紧凑列表。
- 每行：头像、姓名、岗位、状态、绑定 Agent、当前任务、今日 Token、最近活跃。
- 悬停/选中：显示快捷操作（对话、工作台、停用）。
- 空状态：引导“先创建 Agent，再创建数字员工”。
- 不允许用大下拉承担主选择。

### 3.2 员工工作台

#### 概览

- 状态卡：当前状态、当前任务、当前项目、等待确认数。
- 今日工作：任务数、成功数、接管数、Token。
- 能力雷达（复用 `capability_radar`）。
- 契约红线摘要：cannot_do / must_ask / 自主权。
- 最近活动时间线：任务、对话、学习工件、审批。

#### 工作

- 任务/协作/对话统一时间线。
- 任务行：标题、类型、状态、耗时、尝试次数、Token、项目、查看详情/回放。
- 支持按状态、时间、项目筛选。

#### 项目

- 参与项目卡片：项目名、角色、状态、关联任务数、Token 成本。
- 项目详情：成员、任务、会话、Token 预算与消耗。
- 支持把当前任务/会话关联到项目。

#### Token

- 顶部：今日 / 近 7 天 / 近 30 天 Token 与成本。
- 按天柱状/折线图。
- 按来源：任务 / 对话 / 工具。
- 明细表：时间、来源、场景（任务/会话）、动作（步骤/工具/回复）、模型、
  Token、成本、Trace ID。
- 筛选：时间范围、来源、项目、工具。
- 必须回答“在哪里、做了什么、怎么消耗”。

#### 学习

- 学习工件、失败归因、能力迁移入口。
- 本周成长摘要（复用周报）。

#### 配置

- Agent 绑定：卡片选择器，显示模型、工具、能力、被使用次数。
- 人格、契约、技能、知识库、触发器分组展示。
- 复杂配置用抽屉，不在工作台堆一排按钮。
- 保存后即时刷新头部状态。

### 3.3 对话

#### 直接对话

- 类大模型聊天：消息流、时间、员工头像/名称。
- 工具调用卡片：
  - 工具名、参数、结果摘要、耗时、风险等级。
  - `allow` 直接执行；`ask` 显示“需要确认”卡片；`deny` 显示红线原因。
- 每条员工回复显示 Token 徽标。
- Composer：多行输入、Enter 发送、Shift+Enter 换行、附件、发送中状态。
- 操作：停止、重试、复制、查看 Trace。
- 会话历史：按员工列出，可搜索、归档。

#### 群聊

- 创建群聊：多选数字员工，显示各自 Agent/岗位，设置标题。
- 参与者 chips，可随时增删。
- 路由模式：
  - 自动：按岗位/技能/Agent 能力选最合适员工；
  - 全员：每个员工都回复；
  - 指定：@某员工或手动选择。
- 消息流按员工区分气泡；同一轮多个回复按顺序展示。
- 群聊内仍显示每个员工的工具调用与 Token。

### 3.4 Agent 页面

- Agent 卡片：名称、模型、工具数、能力、状态。
- 显示“被哪些数字员工使用”，支持跳转到员工工作台。
- 创建 Agent 使用分步向导：身份 → 模型 → 工具 → 提示词 → 预览。
- 不把 JSON 配置作为默认主界面；高级配置折叠。

### 3.5 项目页面

- 项目卡片/看板：状态、负责人、成员、任务数、Token 消耗。
- 项目详情：成员、关联任务、关联会话、Token 预算。
- 从员工工作台可直接“加入项目/关联任务”。

## 4. 交互规范

1. **主选择不用大下拉**：Agent、员工、项目等核心对象用卡片选择器、搜索、
   命令面板（`Ctrl/Cmd + K`）。
2. **复杂配置用抽屉**：表单分组、两列布局、内联校验、保存草稿。
3. **状态完整**：loading skeleton、empty、error + retry、disabled、无权限。
4. **操作层级**：主操作 1 个、次操作少量；其余收进“更多”。
5. **即时反馈**：保存/发送/工具调用均有 loading 与 toast；失败保留输入。
6. **键盘**：`/` 聚焦搜索，`Enter` 发送，`Shift+Enter` 换行，`Esc` 关闭浮层。
7. **可访问性**：焦点可见、按钮有 aria-label、颜色不作为唯一状态表达。
8. **响应式**：≥1280px 三栏；1024–1280 两栏；<1024 对话改抽屉。
9. **聊天安全**：工具调用必须展示风险与确认；红线调用不执行并解释原因。

## 5. 视觉系统

- 延续现有深色控制台基调，但统一设计 token：
  - 背景：`--bg` / `--panel` / `--panel-2`
  - 文本：`--text` / `--dim` / `--muted`
  - 状态：绿=成功、橙=进行中、红=失败、蓝=信息
  - 间距：4/8/12/16/24/32
  - 字号：11/12/13/14/18/24
  - 圆角：8/10/14
- 图表：单一强调色 + 语义色；不使用彩虹色。
- 表格：行高 44–52；首列主信息 + 次信息两行；操作列固定宽度。

## 6. 验收标准

- [ ] 创建数字员工时可以从已有 Agent 中选择，并显示 Agent 预览。
- [ ] 选中员工后，左下角员工坞出现，显示状态/当前任务/今日 Token。
- [ ] 员工工作台可查看概览、工作、项目、Token、学习、配置。
- [ ] Token 页能按天、来源、工具查看明细，并能定位到任务/会话/Trace。
- [ ] 点击“去对话”可直接与员工对话，员工可调用工具。
- [ ] 工具调用在消息中以卡片展示；`ask/deny` 有明确提示。
- [ ] 可创建群聊，拉入多个员工，并看到多个员工的回复。
- [ ] 核心流程不依赖大下拉；Agent/员工/项目使用卡片选择器。
- [ ] 所有核心页面具备 loading/empty/error 状态。
- [ ] 1280px 与 1024px 下布局不重叠、不横向滚动。
- [ ] `npm run build` 通过；Playwright 冒烟无 page/console error。

## 7. 分期

- **P0**：员工工作台骨架、Agent 绑定、员工坞、直接对话、Token 概览。
- **P1**：Token 明细与图表、项目参与、工作/会话时间线。
- **P2**：群聊、路由模式、@提及、待确认工具卡片。
- **P3**：Agent/项目页面重做、全站设计系统统一、响应式打磨。
